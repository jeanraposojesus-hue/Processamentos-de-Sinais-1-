Este repositório contém uma série de experimentos práticos sobre os fundamentos de amostragem, aliasing, reconstrução de sinais e processamento multirate.

## Conteúdo do Notebook
1. **Análise de Aliasing**: Demonstração do Teorema de Nyquist com frequências de até 50kHz.
2. **Sinais Chirp**: Comparação de varreduras lineares, quadráticas e logarítmicas.
3. **Análise de Áudio Real**: Estudo harmônico do sinal 'Handel' e sons percussivos.
4. **Subamostragem (Downsampling)**: Degradação por redução de taxa de amostragem.
5. **Sobreamostragem (Upsampling)**: Inserção de zeros e o fenômeno de imagens espectrais.
6. **Reconstrução**: Comparação entre Interpolação Ideal (Sinc) e Zero-Order Hold (ZOH).
7. **Sistemas LTI**: Convolução com resposta ao impulso de ambiente real (reverberação).

## Tecnologias
- Python 3
- Scipy (Signal Processing)
- Matplotlib (Visualização)
- Numpy
